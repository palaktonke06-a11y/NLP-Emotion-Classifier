# 💻 NLP Emotion Classifier

## 📝 Problem Statement
Manually identifying emotions from large volumes of textual feedback, reviews, and messages can be time-consuming. Understanding the emotional tone of text can help organize and analyze feedback more efficiently.

## 💡 Solution
This project uses **Natural Language Processing (NLP)** and **Machine Learning** to classify text into emotion categories. It compares multiple ML approaches and provides an interactive interface where users can enter text and view the predicted emotion.

## 🎯 Reason for Choosing This Project
This project demonstrates practical skills in **NLP, text preprocessing, feature extraction, model comparison, model evaluation, and deployment**. It connects machine learning concepts with a real-world text analytics use case.

## ⚙️ Key Features
- 💬 Text-based emotion prediction
- 🧠 NLP-based text classification
- 📊 Model comparison and performance evaluation
- 🔍 TF-IDF and Bag of Words feature extraction
- 🌐 Interactive Streamlit web application
- 🚀 Saved model pipeline for reusable predictions

## 🔄 Workflow
1. **Load and Inspect:** Load and inspect the dataset.
2. **Data Cleaning:** Clean the text data.
3. **Data Splitting:** Split the data into training and testing sets.
4. **Feature Extraction:** Convert text into numerical features.
5. **Model Training:** Train and compare machine learning models.
6. **Model Evaluation:** Evaluate model performance.
7. **Model Saving:** Save the selected model pipeline.
8. **Deployment:** Deploy the model through a Streamlit interface.

## 📊 Model Evaluation
The models are compared using **test-set accuracy**. The selected model is also evaluated using a **classification report** and **confusion matrix**.

## 🎯 Applications
- Customer feedback analysis
- Review emotion classification
- Text analytics and research
- Exploring emotional patterns in written feedback

## ⚠️ Limitations
Predictions depend on the training data and may not reliably interpret sarcasm, context, or complex expressions. The predicted emotion is a model estimate, not a definitive assessment of a person's feelings.
